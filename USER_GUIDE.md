# File Presenter User Guide

File Presenter shows every file on a USB drive or in a folder (photos, videos, music, PDFs) one at a time in a full browser window, and turns your phone into the remote control. It keeps track of what you've already seen, so you can pick up where you left off.

**Why your computer asks for permission:** The first time you open File Presenter, your computer will warn you that it doesn't recognize the app. Getting an app registered with Apple and Microsoft takes time and money, and I'm not paying for that on a free project. The warning means the app isn't registered, not that a problem was found. Only download File Presenter from the [official releases page](https://github.com/LadariousX/file-presenter/releases/latest), where you can also read its source code, then follow the first-time steps below.

## Getting started

| Apple Mac | Windows computer |
|---|---|
| Open **File Presenter.dmg**, drag **File Presenter** into **Applications**, then open it from there. | Open **File-Presenter.exe**. |
| **First time:** if macOS says the app can't be opened, go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. If it asks about the local network or incoming connections, click **Allow**. | **First time:** if a blue "Windows protected your PC" box appears, click **More info → Run anyway**. If the firewall asks, allow **Private networks**. |
| **Full screen:** click the browser window, then press **fn + F** (or **Control + Command + F**). Press it again to leave full screen. | **Full screen:** click the browser window, then press **F11** (on some laptops **fn + F11**). Press it again to leave full screen. |

## Using it

1. Your web browser opens by itself. Pick the USB drive or folder and click **Present this folder**.
2. Scan the QR code on the screen with your phone's camera and open the link.
3. Use your phone as the remote:
   - **◀ ▶** go to the previous or next file.
   - For videos: **⏯** plays and pauses, **↺ 10s / 10s ↻** skip back or ahead, and you can drag the dot on the timeline.
   - **Autoplay** moves to the next file every 5 seconds (videos play to the end first). Tap it again to stop.
   - **Files** lets you jump to any folder or file.
   - **Favorite** moves the current file into a **Favorites** folder on the drive. Tap it again to put it back.
4. To stop, close the small **File Presenter** window.

## Troubleshooting

- **The remote won't connect:** your phone and the computer must be on the **same Wi-Fi network**. If there's no Wi-Fi, turn on your phone's Personal Hotspot and connect the computer to it. Guest and some work or school networks don't let devices see each other, so try another network or the hotspot.
- **The browser didn't open:** click the link in the small File Presenter window.
- **"This browser can't open this file":** the browser can't play that file type. Press ▶ to move on.
